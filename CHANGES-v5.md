# v5 changes

- User-selectable background layer with persistent opacity.
- Desktop-wallpaper translucent mode.
- Custom controller-aware image browser; no native file picker.
- Vista/Aero ribbons and Win98 starfield remain separate animated overlay layers.
- One-time optional WinDS PRO 2026.08.22 detection/download/install offer.
- MediaFire landing-page resolver so the expiring direct CDN URL is not hard-coded.
- Byte-accurate WinDS PRO download progress and Kadia-styled install progress.
- XInput navigation added to K-Lite failure/retry dialog and all new dialogs.
- Startup storefront detection for Steam, Epic, GOG, EA/Origin, Amazon Games, Ubisoft Connect and Battle.net.
- Missing storefronts are removed from PC Games at runtime.
- Recursive asynchronous scan of all mounted drives for ROM/disc-image extensions.
- Persistent per-file console classification with Unknown and None/ignore states.
- Dynamic Unknowns section populated from classified ambiguous ROM images.
